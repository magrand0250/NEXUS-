# NEXUS - Proyecto C# (.NET)

Proyecto desarrollado para la materia de Programación II (Hito 3).

## 🚀 Descripción
NEXUS es una aplicación orientada a objetos en C# que gestiona entidades (como personajes), implementando encapsulamiento, herencia y lógica de interacción mediante propiedades y métodos.

## 🛠️ Tecnologías
* Lenguaje: C#
* Framework: .NET 8.0 / 10.0
* IDE: Visual Studio Community

## 📂 Estructura del Código
* `Program.cs`: Contiene la clase base `Personaje` y la lógica principal de ejecución.
